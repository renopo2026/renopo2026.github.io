ホームプライバシーポリシー利用規約

プライバシーポリシー

最終更新日：2026年10月10日

Auto Clip Studio（以下「本アプリ」）は、運営者本人が切り抜き動画の制作に使う個人用ツールです。本ポリシーは、本アプリがGoogleのAPIを通じて取得するデータの扱いを説明します。

1. 取得するGoogleユーザーデータ

  • Google Drive：本アプリが運営者のDriveに作成・保存したファイル（参照音声、画像など）と、運営者が指定したフォルダ内のファイル。
  • Google スプレッドシート：運営者が作成した設定シートの内容（キャラクター設定・キーワードなど）。
  • YouTube：運営者のチャンネルへの動画アップロードに必要な権限。チャンネルの他のデータは取得しません。

2. 利用目的

取得したデータは、切り抜き動画の制作（候補区間の決定、文字起こし、テロップ・イラストの作成、動画のアップロード）にのみ使用します。広告、販売、第三者への提供、機械学習モデルの一般的な学習には使用しません。

3. 保存と保護

  • 認証情報（OAuthトークン）は、GitHubとCloudflareの暗号化されたシークレット保存機能にのみ保存します。
  • 制作中のデータは、運営者が管理するCloudflare R2とGoogle Driveに保存します。
  • YouTubeから取得した音声は、運営者が残す設定にしない限り、取得から30日で自動削除します。

4. 第三者との共有

Googleユーザーデータを第三者に販売・共有することはありません。ただし、文字起こしのために配信音声を文字起こしサービス（例：AssemblyAI、Soniox、ElevenLabs）へ送信することがあります。これらに送るのは配信の音声であり、Googleアカウントの個人情報は含みません。

5. Google API サービスのユーザーデータに関するポリシーへの準拠

本アプリによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

Auto Clip Studio's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. データの削除

運営者は、Googleアカウントのサードパーティ アクセスからいつでも本アプリのアクセスを取り消せます。取り消し後、保存済みのトークンは使用できなくなり、運営者が削除します。
